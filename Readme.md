# Support Ticket Triage & SLA Monitor

A small Python project I built to practice how a support team sorts tickets and tracks deadlines.

# What it does
1. Reads a list of support tickets from a CSV file.
2. Gives each ticket a category (like Login or Billing) and a priority from P1 (most urgent) to P4.
3. Checks whether each ticket is Met, Breached, At Risk, or On Track against its deadline.
4. Creates a colored report I can open in the browser.

# How to run

python generate_data.py
python main.py
python test_triage.py
